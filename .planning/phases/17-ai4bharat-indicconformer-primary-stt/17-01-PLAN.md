# Phase 17 Plan: AI4Bharat IndicConformer Primary STT Migration

## Objective
Establish AI4Bharat IndicConformer as FLOVA's PRIMARY speech-to-text engine while maintaining the existing Groq Whisper implementation as the robust, secondary fallback. The voice capture, financial intent extraction, and `/add` review flows must remain completely intact.

---

## Architecture & Work Breakdown

### Task 1: Build FastAPI IndicConformer STT Service (`ai-engine/stt_service/`)
- **Location:** `ai-engine/stt_service/`
- **Components:**
  - `config.py`: Port, internal API key (`FLOVA_STT_INTERNAL_KEY`), model paths, timeout, supported languages (`kn`, `hi`, `te`, `ta`, `ml`, `en`).
  - `audio.py`: Audio preprocessing pipeline converting incoming base64 / binary payloads into 16 kHz mono WAV via `ffmpeg` / `scipy`.
  - `conformer_engine.py`: IndicConformer inference engine with singleton model caching in memory. Handles both real ONNX/PyTorch model checkpoints and robust fallback decoding when model files are initializing or offline.
  - `main.py`: FastAPI application exposing:
    - `GET /health`: Service health, uptime, memory consumption, loaded model checkpoints.
    - `POST /transcribe`: Accepts `{ audioBase64, mimeType, language }`, validates `X-FLOVA-STT-KEY`, returns `{ transcript, language, provider: "indicconformer", duration_ms }`.
    - `GET /models`: Lists available language checkpoints.
  - `requirements.txt`: Minimal dependencies for standalone deployment.

### Task 2: Update Edge Function `process-voice` with Primary/Fallback Routing
- **Location:** `backend/supabase/functions/process-voice/index.ts`
- **Logic:**
  - Read `INDICCONFORMER_URL` (default `http://127.0.0.1:8001/transcribe` or cloud endpoint) and `INDICCONFORMER_KEY`.
  - Primary attempt: If `INDICCONFORMER_URL` is set, send audio to IndicConformer with a 6-8 second abort timeout.
  - If IndicConformer returns HTTP 200 and a non-empty transcript, set `transcript` and `stt_provider = "indicconformer"`.
  - Fallback attempt: If IndicConformer is unset, unreachable, times out, or returns 5xx/empty text, fall back immediately to Groq Whisper (`whisper-large-v3-turbo` / `whisper-large-v3`) with self-healing model discovery. Set `stt_provider = "whisper"`.
  - Pass the resulting transcript directly to Groq LLM (`llama-3.3-70b-versatile` / active chat model) for financial intent extraction.
  - Stamp `stt_provider` onto the root response and each candidate object in `candidates`.

### Task 3: STT Benchmarking Suite
- **Location:** `ai-engine/benchmark_stt.py`
- **Coverage:**
  - Test phrases across Kannada, Hindi, Telugu, Tamil, and English with financial amounts, gig earnings, fuel expenses, and code-switched phrasing.
  - Benchmark IndicConformer vs Groq Whisper:
    - Latency (ms) per utterance.
    - Memory footprint (MB).
    - Transcription accuracy / Indic script preservation.
  - Outputs a structured markdown benchmark comparison report.

### Task 4: Automated Testing & Invariant Verification
- **Unit & Integration Tests:**
  - `ai-engine/tests/test_stt_service.py`: Tests for FastAPI endpoints, audio conversion, authentication, language selection, and error handling.
  - `frontend/src/services/__tests__/sttProviderMigration.test.ts`:
    - Tests IndicConformer primary STT success path.
    - Tests seamless Whisper fallback when primary fails or times out.
    - Tests provider provenance recording (`stt_provider: "indicconformer"` vs `"whisper"`).
    - Verifies financial intent extraction produces valid integer paise amounts regardless of STT provider.
    - Verifies candidate UUID stability and user confirmation requirement before saving.
- **Regression Gates:**
  - All existing frontend tests (203 tests) must pass.
  - Frontend production build (`npm run build`) must succeed.

---

## Invariants & Guardrails
1. **Zero Hallucinated Arithmetic:** The financial engine remains authoritative in integer paise.
2. **Deterministic Fallback:** No voice input is ever lost; Whisper immediately recovers any failed IndicConformer request.
3. **No Unconfirmed Database Writes:** All voice candidates must be reviewed and confirmed by the user in `/add`.
4. **Secret Hygiene:** All tokens and keys stored in environment variables; zero leaks to client.
