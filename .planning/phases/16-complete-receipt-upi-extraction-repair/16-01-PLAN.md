# Plan 16-01: Complete Receipt & UPI Extraction Pipeline Repair

## Goal
Implement a robust, end-to-end receipt and UPI screenshot capture and extraction pipeline supporting files up to 20 MB with client-side downscaling/compression, active Groq vision models (`qwen/qwen3.8-27b`), itemized line-item extraction, arithmetic verification, UPI status classification, multi-step progress UI, and regression tests.

---

## Tasks

### Task 1: Client-Side Image Optimizer & 20MB Validation
- **File:** `frontend/src/services/imageOptimizer.ts`
- Implement `validateAndOptimizeImage(file: File)`:
  - Check file size $\le 20\text{ MB}$ (throw clear error if $>20\text{ MB}$).
  - Validate MIME types (`image/jpeg`, `image/png`, `image/webp`, `image/jpg`).
  - Downscale if width or height $> 1920\text{px}$ using HTML Canvas while preserving aspect ratio.
  - Compress output to JPEG/WEBP with 0.85 quality.
  - Return base64 Data URL and file metadata (`originalSize`, `optimizedSize`, `dimensions`).

### Task 2: Supabase Edge Function Upgrade (`extract-receipt`)
- **File:** `backend/supabase/functions/extract-receipt/index.ts`
- Upgrade vision model preferences:
  - First choice: `qwen/qwen3.8-27b`
  - Dynamic discovery from Groq models list (`/vision|vl|qwen.*27b/i`)
- Upgrade extraction prompt:
  - Extract subtotal, taxes/GST, discounts, final payable amount.
  - Extract itemized line items (`name`, `quantity`, `price`).
  - Strict anti-hallucination rules (reject phone numbers, GSTIN, invoice IDs as amounts).
  - Classify UPI apps (`google_pay`, `phonepe`, `paytm`, `cred`, `bhim`, `other`) and statuses (`successful`, `pending`, `failed`, `unknown`).
  - Verify arithmetic: flag `arithmeticDiscrepancy` if `subtotal + tax - discount != final_amount`.
  - Enforce ₹10,00,000 maximum transaction limit.
- Structured error handling: Return informative JSON error messages and CORS headers.
- Deploy to remote Supabase project `msjzkylvafuwlkkujxpv`.

### Task 3: Frontend Receipt Extraction Service Upgrade
- **File:** `frontend/src/services/receipt.ts`
- Integrate `validateAndOptimizeImage`.
- Handle Supabase Edge Function errors gracefully:
  - Parse error JSON from response or `error.context` if available.
  - Provide human-friendly error messages if rate-limited or unavailable.
  - Fallback to offline heuristic parser when offline or in case of network timeout.
- Update `ExtractedReceiptCandidate` types in `frontend/src/types/contracts.ts` to include `subtotalPaise`, `taxPaise`, `discountPaise`, `items`, and `arithmeticDiscrepancy`.
