# Phase 9.1 User Acceptance Testing (UAT)

## Scenario 1: Language Pinned Transcription (Kannada)
- **Action**: Worker selects "Kannada (ಕನ್ನಡ)" from language dropdown and speaks "ಇವತ್ತು ಪೆಟ್ರೋಲ್ಗೆ 300 ರೂಪಾಯಿ ಖರ್ಚು ಮಾಡಿದೆ."
- **Expected**: Whisper receives `language="kn"`. Candidate transaction populated with amount ₹300, category "fuel", and expense type "work".
- **Verification**: Verified via `multilingualVoice.test.ts` Scenario 3 & 13.

## Scenario 2: Hindi Living Expense Extraction
- **Action**: Worker speaks or types "चाय और समोसे पर 40 रुपये खर्च किए" with Hindi selected.
- **Expected**: Candidate transaction populated with amount ₹40, category "food", and expense type "living".
- **Verification**: Verified via `multilingualVoice.test.ts` Scenario 6.

## Scenario 3: Truthful Uncertainty / Missing Amount (Kannada)
- **Action**: Worker says "ಪೆಟ್ರೋಲ್ ಹಾಕಿಸಿದೆ" without specifying amount.
- **Expected**: Amount remains `null`, `needsReview` set to `true`, and clarification question asking for amount is returned. No database record created before review.
- **Verification**: Verified via `multilingualVoice.test.ts` Scenario 7.

## Scenario 4: Platform Expected Payout Isolation (Telugu)
- **Action**: Worker says "సోమవారం స్విగ్గీ నుండి 1800 వస్తుంది".
- **Expected**: Classified as `expected_payout` with source "Swiggy" and amount 1800. Never created as an ordinary income transaction.
- **Verification**: Verified via `multilingualVoice.test.ts` Scenario 8.

## Scenario 5: Balance Check-in Segregation (Urdu)
- **Action**: Worker says "میرے پاس نقد 500 اور بینک میں 2000 ہیں".
- **Expected**: Classified as `balance_checkin` with cash 500 and bank 2000. Never converted into a transaction.
- **Verification**: Verified via `multilingualVoice.test.ts` Scenario 9.

## Scenario 6: Multilingual Deterministic Financial Queries
- **Action**: Worker asks "कितना पैसा बचा है?", "ಎಷ್ಟು ದುಡ್ಡು ಉಳಿದಿದೆ?", "کتنے پیسے بچے ہیں؟", or "ఎంత డబ్బు మిగిలి ఉంది?".
- **Expected**: Classified as `financial_query`, answered using M3 balance engine with verified confirmed balance (₹2,400).
- **Verification**: Verified via `multilingualVoice.test.ts` Scenario 10.
