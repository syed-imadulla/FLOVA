# Plan 09.1-01: Multilingual Voice Support & Language-Specific Financial Extraction

## Goal
Implement language-parameter routing for Groq Whisper transcription, multilingual prompt guidelines for Groq Llama 3.3 intent extraction, local fallback support across English, Hindi, Kannada, Urdu, and Telugu, a compact language selector in `VoiceCapturePage.tsx`, and a dedicated automated test suite verifying all 5 languages.

## Tasks
1. **Edge Function Update (`backend/supabase/functions/process-voice/index.ts`)**:
   - Accept optional `language?: string` in `ProcessVoiceRequest`.
   - Pass ISO 639-1 code to Whisper `FormData` if `language && language !== "auto"`.
   - Update Llama 3.3 `systemPrompt` with Indic script handling, currency words, work vs living disambiguation, and raw utterance preservation.
2. **Frontend Service Update (`frontend/src/services/voice.ts`)**:
   - Add `language?: string` to `VoiceProcessInput`.
   - Pass `language` to Supabase Edge Function invoke call.
   - Pass `language` to local `extractTransaction` fallback.
3. **Local Extractor Update (`frontend/src/voice/extractTransaction.ts`)**:
   - Normalize Indic numerals (Devanagari, Kannada, Telugu, Eastern Arabic) to ASCII digits.
   - Extend keyword maps and regexes for income, expenses, work vs living, categories, expected payouts, check-ins, and queries across English, Hindi, Kannada, Urdu, and Telugu.
4. **UI Language Selector (`frontend/src/pages/VoiceCapturePage.tsx`)**:
   - Add compact language dropdown: Auto Detect (`auto`), English (`en`), Hindi (`hi`), Kannada (`kn`), Urdu (`ur`), Telugu (`te`).
   - Wire selection to `processVoice({ language: selectedLanguage })`.
5. **Automated Test Suite (`frontend/src/services/__tests__/multilingualVoice.test.ts`)**:
   - Test 1: English work expense (₹300, work, fuel, needsReview: false).
   - Test 2: Hindi work expense ("आज पेट्रोल पर 300 रुपये खर्च किए।").
   - Test 3: Kannada work expense ("ಇವತ್ತು ಪೆಟ್ರೋಲ್ಗೆ 300 ರೂಪಾಯಿ ಖರ್ಚು ಮಾಡಿದೆ.").
   - Test 4: Urdu work expense ("آج پیٹرول پر 300 روپے خرچ کیے۔").
   - Test 5: Telugu work expense ("ఈరోజు పెట్రోల్ కోసం 300 రూపాయలు ఖర్చు చేశాను.").
   - Test 6: Hindi living expense ("चाय और समोसे पर 40 रुपये खर्च किए" -> ₹40, living, food).
   - Test 7: Kannada missing amount ("ಪೆಟ್ರೋಲ್ ಹಾಕಿಸಿದೆ" -> null amount, needsReview: true).
   - Test 8: Telugu expected payout ("సోమవారం స్విగ్గీ నుండి 1800 వస్తుంది" -> expected_payout, 0 transactions created).
   - Test 9: Urdu balance checkin ("میرے پاس نقد 500 اور بینک میں 2000 ہیں" -> balance_checkin, cash: 500, bank: 2000).
   - Test 10: Multilingual financial queries (Hindi, Kannada, Urdu, Telugu deterministically resolved).
   - Test 11: Code-switching / Hinglish ("300 rupaye petrol ke liye diye").
   - Test 12: Multilingual candidate confirmation with UUID idempotency.
   - Test 13: Edge Function Groq Whisper + Llama 3.3 remote routing.
6. **Verification**:
   - Run backend test suite.
   - Run complete frontend test suite.
   - Run TypeScript check & Vite build (`npm run build`).
   - Run secret scan on `frontend/dist/`.
